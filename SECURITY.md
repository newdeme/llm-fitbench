# Security Policy / 安全策略

## Scope / 支持范围

This project is a set of local benchmarking scripts (`scripts/`), documentation and example banks. The scripts talk only to a model engine you run yourself (default `127.0.0.1`). Relevant reports: unexpected file access or deletion, path-handling flaws, unsafe handling of engine output.

## Reporting / 如何报告

**Do not open public issues for vulnerabilities.** Use GitHub private vulnerability reporting: repository page → Security → Report a vulnerability. 请勿在公开 Issue 提交漏洞细节。

If that channel is not enabled, open an issue *without* details asking the maintainer to enable it.
